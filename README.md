# LabTam/UFRN — versão para GitHub Pages

Este pacote já está organizado para publicação direta no GitHub Pages.

## Estrutura principal

- `index.html` — página inicial
- `equipe.html` — equipe
- `midias.html` — YouTube, Instagram, LinkedIn e LabTam na UFRN
- `noticias.html` — notícias
- `pesquisa.html` — linhas de pesquisa
- `equipamentos.html` — infraestrutura
- `publicacoes.html` — publicações
- `editais.html` — editais
- `auditorio.html` — auditório
- `contato.html` — contato
- `assets/` — CSS, JavaScript e imagens do site
- `.nojekyll` — compatibilidade com GitHub Pages

## Como subir no GitHub

1. Extraia o ZIP.
2. Abra a pasta `labtam-github-pronto`.
3. Selecione **todos os arquivos e a pasta `assets`**.
4. No repositório do GitHub, use **Add file → Upload files**.
5. Arraste tudo para a raiz do repositório.
6. Confirme o commit.
7. Em **Settings → Pages**, use `Deploy from a branch`, branch `main`, pasta `/(root)`.

A estrutura no GitHub deve mostrar `index.html` e `assets/` no mesmo nível.
