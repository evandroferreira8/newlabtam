# Talk Show das Engenharias no portal LabTam

Esta pasta incorpora ao portal do LabTam/UFRN o especial fotográfico e editorial do I Talk Show das Engenharias (15 de outubro de 2026, Sebrae, Natal/RN).

- `index.html`: conteúdo original preservado, com navegação institucional e metadados próprios do LabTam.
- `style.css` e `script.js`: base do especial original, mantendo os 26 registros, filtros, navegação pelo teclado, ampliação e links para fotografias.
- `labtam-overrides.css`: adaptação visual com azul #164194, azul-claro #0095DB, verde #009D43 e tipografia institucional.
- O portal principal e a página Comunicação contêm um link para este especial.

## Imagens

As fotografias são servidas pelo repositório público original `evandroferreira8/TalkShowEngenhariasUFRN`, em `https://evandroferreira8.github.io/TalkShowEngenhariasUFRN/assets/photos/`, evitando duplicação de dezenas de arquivos. O crédito é de **Rodrigo Melo**. Para tornar o especial autônomo em outra hospedagem, copie `assets/photos/` para esta pasta e ajuste os caminhos em `index.html` e `script.js`.

## Publicação

Página integrada: `/newlabtam/talkshow/` no GitHub Pages atual ou `/talkshow/` caso a raiz do site passe a ser o domínio oficial. O repositório original do Talk Show permanece intacto.
